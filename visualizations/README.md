# Visualizations

Run `usgs_earthquake_data_analysis.py` from the repository root, then move the resulting PNG plots into this folder if you'd like to show them on GitHub.

Expected image filenames:

- `Yi_distributions.png`
- `Yi_boxplot.png`
- `Yi_correlation.png`
- `Yi_relationships.png`
- `Yi_multivariate.png`

No plots are bundled here yet because they need to be generated from the USGS data.
